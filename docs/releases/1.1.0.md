# ShortCut Studio 1.1.0 (build 1140)

- App identity is now **ShortCut Studio** (bundle `local.datdo.shortcutstudio`, data in `~/Library/Application Support/ShortCut Studio` and `%LOCALAPPDATA%\ShortCut Studio`). The word "Beta" is gone from the app name, window titles, installer and file names. Data of the old "ShortCut Studio Beta" app is not read or migrated.
- Ports stay 5373 / 8987, so the old Beta app and this app cannot run at the same time. Quit and delete the old Beta app first.
- Internal identifiers still say `beta` (profile id `beta`, `SHORTCUT_BETA_*` environment variables, `release/beta/` output folder, `BETA_RELEASE`). Renaming them is a separate change.
- Main cut rules: remove advertising, third-party redirects, personal/contact information and brand names that are not the video's subject; product review/unboxing keeps the product; each part must export longer than 61 s; join test after every cut; guide-style part titles for product videos. TXT prompt is v25 (v24 stays importable).
- Not signed or notarized (macOS ad-hoc, Windows unsigned): Gatekeeper / SmartScreen will warn on other machines.
